# Mu3e

Working repository for my Mu3e work at ETH Zürich (Swiss Summer School Particle Physics Program, S3P3): SciFi / Pixel control pages and PySequencer scripts for the MIDAS online system.

## Layout

| Path | Content |
|---|---|
| `LOGBOOK.md` | Running log of the work |
| `docs/dev/` | Design notes, TODOs, topology, workflow (`page/` custom-page I/O, `code-notes/` calibration & scripts design, `old/` superseded notes) |
| `docs/mockups/` | HTML mockups of the custom control pages (`old/` = earlier versions) |
| `docs/images/` | Screenshots and pictures |
| `scripts/` | One-off helper scripts (ODB seeding / restructuring) |
| `report/` | S3P3 project report (LaTeX, PDF, docx) |
| `presentations/` | S3P3 / ETH meeting slides |

## Separate repositories (not tracked here)

`midas/`, `online/`, `sequencer_scripts/` and `mu3especbook/` are independent clones and are git-ignored.
